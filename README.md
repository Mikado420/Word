# 赤シート単語帳

受験生向けの英単語帳Webアプリ（単一HTML）。

- **インプットモード**：紙の単語帳風ページ。赤シートで意味を隠し、タップでめくる。色つき付箋とメモを貼れる。
- **アウトプットモード**：1枚ずつのカード復習。4段階の自己採点からFSRSで次回出題日を計算。読んだページ・付箋だけに絞って出題可能。

学習記録はブラウザの localStorage に保存されます。`index.html` をブラウザで開くだけで動きます。

## ファイル構成

```
index.html        画面の骨組み（viewport設定を含む）
css/style.css     デザイン・テーマ（ライト/ダーク）
js/data.js        保存済みの単語データの読み出し・登録済みデータ（BOOKS）の一覧
data/             単語データ（書き起こしテキスト）
js/import.js      単語データの読み込み（テキストを解析してこの端末に保存・初回の自動読み込み）
js/storage.js     学習記録の保存（localStorage）
js/fsrs.js        復習間隔の計算（FSRS）
js/utils.js       共通ヘルパー
js/redsheet.js    赤シート（ドラッグで動かせる半透明の板）
js/book.js        インプットモード（単語帳ページ・赤シート・付箋）
js/review.js      アウトプットモード（ダッシュボード・復習カード）
js/updater.js     自動更新（version.json の監視）
js/menu.js        左上メニュー（モード・ページ・付箋・単語データ・表示テーマ）
js/app.js         モード切替・キー操作・ズーム防止・起動
sw.js             Service Worker（オフライン対応・最新優先）
manifest.json     ホーム画面に追加するための設定
```

ES Modules を使っていないので、`index.html` をダブルクリックで開いても動きます。

## 自動更新のしくみ

アプリは起動時・画面に戻ったとき・3分ごとに、公開中の `index.html` と、そこから読み込む CSS・JS の中身を取得して比べます。
1文字でも変わっていれば新しい版と判断して自動で再読み込みします（版番号の管理は不要）。
復習の途中や付箋の編集中は中断せず、画面下のバナーで知らせて、ダッシュボードに戻った時点で反映します。

学習記録（localStorage）は更新しても消えません。GitHub Pages は Settings → Pages の「Deploy from a branch（main / root）」で公開します。

## 単語データ

単語データは `data/` にテキストで登録しています（一覧は `js/data.js` の `BOOKS`）。

| ファイル | 内容 |
|---|---|
| `data/verbs-stage1.txt` | 動詞 Stage 1（No.1〜49） |

まだ単語を読み込んでいない端末では、起動時に `BOOKS` の先頭を自動で読み込みます（`index.html` を直接開いた場合は取得できないので読み込み画面になります）。
左上メニューの「単語データ」からは、登録済みデータの選び直しや、手元のテキストファイル・貼り付けでの読み込みもできます。
読み込んだデータと学習記録はその端末のブラウザ内（localStorage）に保存されます。

データを追加するときは `data/` にテキストを置き、`BOOKS` に1行足します。

書式（`js/import.js` の先頭にも説明あり）：

```
No.1
英語：【赤字：borrow】 a book 【赤字：from】 the library
日本語：図書館から本を【赤字：借りる】

1. borrow
【発音】[bárou]
【意味】
①〜を借りる
◆ borrow A from B ＝ BからAを借りる
◇ borrower（名）＝ 借り手
⇔ lend ＝ 〜を貸す
【補足】 …  【例文】 …  【関連表現】 …  【名詞の意味】 …  【活用】 …
【問題】 …
【答え】 …
```

- `【赤字：…】` は赤字（赤シートで消える部分）。【意味】の中に `【赤字：…】` があればその部分だけ赤字、無ければ括弧書き以外がすべて赤字になる
- ◆熟語・構文、◇派生語、⇔反意語。`（名）（形）（副）（前）（接）` は品詞の囲みになる
- `【問題】` だけで `【答え】` が無い場合は問いだけを表示

## アウトプットの出題設定

ダッシュボードの「出題設定」から変更できます。

- **出し方**（複数可）：英→和／フレーズ→和／和→英（頭文字ヒント）／和フレーズ→英。英→和と和→英は別々に記録・スケジュール
- **出題範囲**：読んだ単語／付箋（色で絞り込み可）／すべて／番号で指定
- **出題する語**：復習が必要な語（普段）／範囲をすべて（総ざらい）
- **順番**：忘れかけ順／番号順／ランダム／苦手順
- **試験日**：目標記憶率を 90%→92%（30日前）→95%（7日前）→97%（直前）と上げ、試験の前日までに全語がもう一度出るよう間隔を調整
- **1日の新しい単語**：自動（試験の2週間前までに一巡できる数、復習が溜まっている日は減らす）／手動
